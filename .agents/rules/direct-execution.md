# Regla de Ejecución Directa

- No utilices planning mode ni solicites confirmación previa para editar archivos, crear componentes o ejecutar comandos de verificación.
- Aplica directamente las modificaciones en el código fuente, realiza las pruebas necesarias en segundo plano y entrega el resultado final ya funcionando.
- No pidas permisos para tareas de desarrollo solicitadas por el usuario; asume aprobación tácita para avanzar rápido.
